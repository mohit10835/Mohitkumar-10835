# Student Attendance Management System (Mini Project)

## 📌 Project Overview
This project is a **Student Attendance Management System** developed using **C programming language**.  
The system uses a **simple 1D array-based approach** to store, display, and count student attendance.

This mini project is designed to strengthen the understanding of **arrays, loops, conditional statements, and functions**.

---

## 🎯 Aim of the Project
The aim of this project is to develop a Student Attendance Management System that records, displays, and counts the attendance of students using a simple array-based approach.

---

## ❓ Why This Project?
- Manual attendance systems are time-consuming and error-prone  
- Helps beginners understand **core C programming concepts**  
- Provides a real-life use case of arrays and loops  
- Suitable for academic mini projects  

---

## 🧠 Concepts Used
- 1D Arrays for storing attendance data  
- Loops for traversing student records  
- Conditional statements (if–else) for attendance logic  
- Functions for modular program structure  

---

## 🛠️ Technology Used
- **Programming Language:** C  
- **Concepts:** Arrays, Loops, If–Else, Functions  
- **Compiler:** GCC / Turbo C / Code::Blocks  

---

## ⚙️ How the Project Works (Workflow)
1. A 1D integer array is declared where each index represents a student  
2. `1` represents **Present** and `0` represents **Absent**  
3. Attendance is entered using a loop  
4. Attendance is displayed student-wise  
5. Present and absent students are counted using conditions  

---

## 📥 Input Format
- Enter number of students  
- Enter attendance for each student  
  - `1` → Present  
  - `0` → Absent  

---

## 📤 Output
- Displays attendance status of each student  
- Shows total number of present students  
- Shows total number of absent students
